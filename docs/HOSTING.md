# Free hosting with GitHub Pages

The website is a static HTML page with local portrait artwork. No application server or paid hosting plan is needed.

In this repository, open Settings → Pages. Select Deploy from a branch, then choose main and /docs. Save. GitHub will run its Pages deployment. Confirm its successful deployment before sharing the site URL shown there.

The runnable Django projects are linked from the portfolio; GitHub Pages does not run Django backends.

The contact action opens the visitor's email application. It does not pretend to send a message from a form.
