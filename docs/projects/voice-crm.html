Voice CRM Assistant

A Django REST and React PWA prototype for capturing sales conversations and turning their text into structured customer and interaction records.

The problem

Sales staff often need to enter customer details after a conversation. This prototype explores a recording-first interface and structured extraction to reduce repeated manual entry.

What it does

  • Capture audio in the browser with recording feedback.
  • Expose transcription and text-extraction endpoints through Django REST Framework.
  • Represent customer information and interaction history as separate database models.
  • Provide a React PWA frontend, a standalone recording demo, and Django admin views.

API entry points

EndpointPurpose
GET /api/health/Backend health
POST /api/transcribe/Mock transcription integration
POST /api/extract/Structured text extraction

How it works

Capture a conversation

The browser recording interface captures audio and displays recording state.

Obtain transcript text

The transcription path is currently mocked; it demonstrates the integration contract rather than a connected speech provider.

Extract fields

Submit transcript text to the extraction endpoint for structured customer and interaction output.

Review the result

Inspect structured JSON and customer information through the interface; records can be managed in Django admin.

Design decisions

  • Use a Django REST backend so the recording interface and data-extraction API can evolve separately.
  • Keep customer details separate from interaction records so multiple conversations can be associated with one customer.
  • Offer a standalone HTML demo alongside the React PWA for a lightweight interface walkthrough.

Current scope

Speech-to-text is mocked. The presence of a user model does not establish that all API routes have production authentication. This is a prototype, not an audited live CRM or a deployed speech-recognition service.

Next engineering steps: connect a speech provider, validate extracted fields, add explicit API permissions, and evaluate transcription and extraction against reviewed examples.

Evidence and verification

The README provides local setup, health and extraction API examples, database-model descriptions, and the demo entry point. No claim of production accuracy or load capacity is made.
