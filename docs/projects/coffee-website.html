The problem

This learning project explores how Django routes, templates, static files, and a relational database fit together in a small website.

What it does

  • Organize pages through Django application and project configuration.
  • Render HTML templates and serve static website assets.
  • Include shop and checkout interface templates.
  • Use SQLite for a lightweight local-development setup.

How it works

Request a page

The browser requests a URL from the Django development server.

Resolve the route

Django URL configuration selects the matching view.

Render a template

The application returns server-rendered HTML using its template files.

Load page assets

The browser loads CSS, scripts, and images from the static asset directory.

Design decisions

  • Use server-rendered templates to learn Django fundamentals before introducing a separate frontend framework.
  • Keep local setup simple with a Python virtual environment and SQLite.

Current scope

Learning prototype. Shop and checkout templates do not establish that payments or fulfilment work. Existing development settings require review and replacement before deployment; no production-readiness claim is made.

The stronger current backend examples are MarketLens, FuelRoute, and Webhook Ledger.

Evidence and verification

The README documents the repository structure and local setup. A full functional or security audit is not documented.
