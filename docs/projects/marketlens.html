MarketLens

Evidence-led market research and portfolio monitoring with a FastAPI backend, a source-aware dashboard, and a deterministic LangGraph workflow.

The problem

Market news, holdings, and price history often live in separate tools. MarketLens brings them into a single research workspace while making source freshness and missing evidence visible.

What it does

  • Import CSV holdings and calculate valuation and concentration flags without treating missing prices as zero-value losses.
  • Collect configured RSS feeds, match company mentions, and deduplicate headlines. Optional article extraction uses a hostname allowlist and robots checks.
  • Refresh cached daily NSE candles through an unofficial Yahoo Finance adapter intended for personal testing, with source timestamps and failure cooldowns.
  • Save research snapshots and JSON exports. A deterministic LangGraph workflow gathers evidence, calculates a trend screen, and checks the inputs.

How it works

Import holdings

Validate symbols, quantities, and average costs before replacing the saved portfolio.

Collect evidence

A manual API call or scheduled worker collects configured news sources and refreshes supported daily-price series.

Assess the portfolio

The API values priced positions, identifies concentration, and flags missing or stale data.

Build a research snapshot

LangGraph gathers evidence, calculates supported metrics, and records a fingerprint and citations.

Inspect the result

The dashboard shows source timestamps, evidence gaps, and research history rather than executing trades.

Design decisions

  • Separate API and collection-worker processes, with PostgreSQL storing shared state. This MVP is not a set of independently deployed microservices.
  • RabbitMQ carries Celery tasks; Celery Beat can schedule collection in the Docker deployment. A separate GitHub scheduled-workflow option is documented for the free-server setup.
  • Sample mode is clearly labelled and uses browser-local synthetic data. Live mode requires a separately running backend and configured sources.

Current scope

Single-owner MVP. No LLM, broker OAuth, trade execution, multi-tenant accounts, or verified fundamentals are connected. Long-term ranking remains unavailable without sufficient fundamental evidence. Yahoo access is unofficial, can be rate-limited, and is not a licensed commercial market feed.

Next engineering steps: licensed data sources, versioned datasets, per-user authentication, and monitored scheduling.

Evidence and verification

The repository documents tests for authentication, portfolio validation, P&L, matching, evidence gaps, timestamps, failed collection, URL restrictions, and static serving. Provider behavior is covered with fixtures; live-provider availability is not guaranteed.
