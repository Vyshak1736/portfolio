FuelRoute

A Django API that plans US driving journeys, chooses fuel purchases along a route, and returns a shareable map with transparent data-coverage limits.

The problem

A driving route alone does not tell a driver where to refuel or how much to buy. FuelRoute combines route geometry with supplied station prices to plan feasible, cost-conscious purchases within a 500-mile vehicle range.

What it does

  • Resolve US city-level endpoints locally using a bundled gazetteer and obtain actual road geometry from OSRM.
  • Import supplied fuel prices, combine duplicate observations, and retain provenance for mapped station coordinates.
  • Find candidate stations near the route using spatial filtering, then use a fixed-route greedy fuel-purchase algorithm.
  • Return fuel quantities, purchase cost, starting-fuel cost when provided, station coverage, routing-call counts, and a saved Leaflet map.

How it works

Submit a journey

POST a start city, destination, optional starting fuel, and optional starting-fuel price.

Resolve and route

Resolve cities locally, then obtain or reuse a cached OSRM road route.

Find fuel candidates

Filter verified station coordinates against a two-mile route corridor using spatial indexing.

Plan purchases

Buy enough to reach a cheaper reachable station, or enough for the next feasible part of the journey.

Verify the detours

Route through chosen stops, recalculate actual leg distances and fuel quantities, and reject unreachable plans.

Return JSON and a map

Show purchases, road distance, coverage metadata, and the route geometry.

Design decisions

  • Normally one routing call for the initial route and one for a route through selected stations. Short journeys need one; fully cached repeats may need none.
  • The greedy algorithm is optimal for fuel purchases on a fixed ordered route under the stated model. Choosing stations across road detours remains a heuristic.
  • Track starting-fuel cost separately from purchases made during the journey; an initially full tank is not silently represented as free fuel.

Current scope

Station-coordinate coverage is partial: the documented enrichment maps 572 of 6,738 stations, with 6,166 unresolved and excluded. This is not nationwide cheapest-fuel coverage, live fuel pricing, or production truck navigation. The public OSRM service can time out.

Next engineering steps: complete sourced station enrichment and use a reliable routing deployment before broader use.

Evidence and verification

The repository documents randomized comparisons with an independent dynamic-programming oracle, range boundaries, partial tanks, duplicate imports, invalid input, route caching, provider failures, and detour feasibility checks.
